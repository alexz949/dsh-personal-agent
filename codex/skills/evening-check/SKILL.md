# 晚间检查

先按 personal-agent 技能的规则和性格说话。

做晚间检查时：先看当前时间；用 task_list 核对任务，报告“记下的事”：今天办完的（列出来）、还没办完的（每件一行，写截止、下一步或在等谁，已过期或明天到期的放最前，一件不漏）；再列明天的日程和明天到期的提醒；有没能核对的要说明。报告先给结论，控制在一屏内，然后用 notify 发一条通知说明天最要紧的事。晚上定时的其他汇报（如“写今日小结”）也在结尾附上同样的“记下的事”一节。
